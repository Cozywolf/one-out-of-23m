## 一、簡單遊玩說明

1. **決定開局條件**：在首頁選擇「台灣六大區」抽籤方式（依出生率隨機、依人口比隨機或自選大區）與「出生年代」（1950–2005 隨機或指定年份），點擊 **「開始這一段台灣人生 →」** 即可出生。
2. **控制時間流速**：
   - 頂部工具列可切換 **1×～16×** 播放速度、點擊 **`+1歲`** 逐年手動推進，或隨時按鍵盤 **空白鍵（Space）** 暫停／繼續。
   - 若想快速觀察多段人生走向，可開啟 **「自動：開」** 由系統自動代選抉擇；也可隨時點擊 **「戶口卡」** 檢視出生證明或匯出 PNG 紀念卡。
3. **做出人生抉擇與調整重心**：
   - 遇到升學、選系、兵役、北漂、買房、婚育、股災、天災或長照等關鍵節點時，系統會自動暫停並彈出決策卡，同時附上 **「📊 時代趨勢」** 統計背景供參考。
   - 左欄下方可隨時調整 **「年度重心」**（均衡生活、全力學習、衝刺工作、省吃儉用、規律養生、陪伴家人），影響每年四維屬性與儲蓄率。
4. **閱讀時間軸與時代脈絡**：
   - **左欄**：身分資料、四維狀態（健康／幸福／知識／人際）、**目前薪資與本年收支**、**總淨資產（現＋股＋房）** 及當前生效的台灣制度。
   - **中欄**：時間軸即時呈現日常切片、**台灣歷史現場**（點擊標題可展開詳情與次層「後世餘波」）、**周圍人的身影**微故事，以及 2027 年後的 **台灣未來預測**。
   - **右欄**：可點擊互動的台灣六大區地圖、4 位同年出生對照同伴、區域 vs 全台存活曲線，以及百歲人生方格。

## 二、起始設定說明（三大開關）

首頁「事件呈現與風險模式」列提供三個可自由切換的起始選項，決定這段人生的資訊密度與風險強度：

| 起始選項 | 預設狀態 | 功能與影響說明 |
| --- | --- | --- |
| **📢 重大惡性社會事件** | **開啟** | 控制是否呈現台灣重大刑案、公安意外與敏感創傷事件細節。**關閉時**會切換為「教學友善模式」（亦可用網址參數 `?edu=1` 直接啟動）：隱藏個人自殺與創傷細節、重大社會刑案改僅呈現「法制與制度改革重點」，且會自動鎖定並關閉「史實模式」。 |
| **⚡ 史實模式** | **關閉** | 僅在「重大惡性社會事件：開啟」時可進一步啟用。**開啟後**，主角會依先天個性、學經歷與所在大區，有機率直接成為重大天災、金融風暴或社會事件之「當事人」，可能面臨鉅額財務損失、長期健康受創，甚至觸發致命結局。 |
| **📚 顯示所有歷史事件** | **關閉** | 控制「台灣歷史現場」卡片的出現頻率。**關閉時（預設）**，系統每 **2–3 年** 才會在當年度符合條件的歷史事件中隨機抽選 **1 則** 顯示，避免事件連發造成資訊過載；**開啟時**，則會完整顯示所有符合當年度與地區條件的台灣歷史事件。 |

## 三、核心特色與系統機制

- **開始工作前零個人資產與合法打工申請（`D01B`）**：出生與求學期間生活費由家庭撫養負擔，開始工作前個人淨資產維持 `NT$0`；僅當滿 15 歲法定打工年齡後，向父母提出課餘打工計畫並成功說服同意（`D01B`），或選擇建教合作、提早學徒就業與大學打工／實習，才會開始累積個人存款。滿法定成年年齡（2023 年前 20 歲、2023 年起 18 歲）後解鎖台股定期定額。
- **生活收支結算、負債危機（`D31`／`D30`）與資產持有檢核**：每年先結算「收入 － 當代生活總支出（依單身／已婚、撫養子女數、區域物價、房租／房貸、長照與養車保養等動態計算）」，現金不足時先賣股支應；若持續負債將依利率滾存，並觸發收支赤字危機（`D31`）或被迫賣房危機（`D30`）。所有賣車、變賣金飾珠寶或賣房選項皆嚴格檢核事前是否實際自購、獲贈、嫁妝或繼承持有。
- **依學群精準分流擇業（`D02`／`D07`／`D07B`）與兵役專業銜接**：大學選系（`D02`）細分為七個學群，並拆分 `car_doctor_pharma`（醫師／牙醫師）、`car_pharma_medtech`（藥師／醫檢師／治療師）、`car_lawyer_cpa`（律師）與 `car_cpa`（會計師）。透過 `required_majors`／`required_sub_majors`／`required_majors_if_uni` 與 `D04` 研發／醫療替代役分流檢查，確保理工生不會出現律師或醫師選項、醫護生不會跳入科技研發役或律師、未雙修跨領域（`uni_cross_coding`）的文商生也不會直接進入半導體或軟體工程跑道；出社會後工作滿 4 年可遇見符合背景的轉職契機（`D07B`），薪水即時依職業倍率與年資連動。
- **存檔與接續人生（v6.17）**：人生進行中會自動存進瀏覽器（每年、每次跳出抉擇或暫停提問、切換分頁或關閉頁面時），連尚未回答的抉擇也會保存。重新整理或下次打開網站時，首頁會出現「上次的人生還沒走完」，按「接續這一生」就從當時的年齡、設定與抉擇繼續；也可以按「捨棄存檔」。人生結束或開始新的人生時會自動覆蓋存檔。
- **財務門檻與敘事一致、人生資料匯出（v6.19）**：「無力資助子女出國留學」只在存款不足、名下也沒有足夠房產淨值可增貸時才記為財務轉折；付得起卻決定不資助時，選項與敘述改為「評估後決定不資助」，自動模式也會依存款寬裕程度提高資助機率。「無力購屋」會寫明是頭期款（現金＋股票）不夠還是年薪未達核貸門檻；若後來購屋或繼承老家，會在該轉折後註明「→ 後於 X 歲取得自住房」。訃聞頁的期末資產結構除了當年名目金額，也顯示折合 2025 年購買力。訃聞頁與人生畫面工具列新增「🧾 匯出這一生詳細資料」，下載 JSON：逐年屬性與資產結構（現金、台股、房價、房貸、薪資、配偶收入、物價指數）、每次抉擇當下的財務快照與各選項門檻判定（是否可選、原因）、財務轉折當下的資產快照、取得房產紀錄、事件與薪資變化。
- **出生年份限縮為 1950–2005（v6.20）**：2005 年後出生的人生多半落在預測期、可玩的歷史與制度內容大幅減少，因此隨機抽選、年份滑桿、快捷年代鈕、出生抽選動畫、世代對照實驗室與自動模擬都只會落在 1950–2005 年；移除「2025（此刻）」快捷鈕。舊版存檔中較晚出生的進行中人生仍可正常接續。
- **依畫面切換背景音樂（v6.22）**：首頁（含書架、Lab）播 andrii g. 的背景音樂；按下開始後進入出生抽籤時首頁音樂淡出，抽完按「出生」才開始播 Morning → Evening 循環；人生結束時畫面與音樂一起在 3 秒內淡出到全黑，接著播人生回顧動畫並換上 Vadim 的 "Atlas Taiwan"，一直播到玩家離開訃聞畫面，再淡出並回到首頁音樂。
- **完整顯示歷史事件餘波（v6.21）**：「台灣歷史現場」卡片的「📌 這件事後來改變了什麼」與史實模式的「制度與社會餘波」不再隱藏未來年份的內容，直接顯示完整的後續影響。
- **人生回顧排序與交往（v6.18）**：同一年內的事件依實際發生順序排列，先出現抉擇（例如「婚姻亮紅燈 → 協議離婚」），再出現它帶來的結果（離婚）；時間軸新增「開始交往」與「分手」。
- **人生回顧動畫（v6.17）**：人生結束時先播放一段回顧：上方是年份與年齡計時、整條人生時間軸，依序呈現出生、結婚、生子、買房、出國、父母離世、退休等大事，以及影響最大的前五個關鍵抉擇（含當下影響、後續回聲與「沒走的路」）和其他重要抉擇，旁邊同步顯示當年的健康、幸福、知識、人際；可暫停、2× 加速、點時間軸跳到某一刻或直接跳過看訃聞。訃聞頁與書架重開的人生也能按「🎬 重播人生回顧」。
- **台灣懷舊彩繪圖案（v6.16）**：開始頁三張圖改為滿月竹搖籃與紅蛋、手牽手圍著台灣島、農民曆撕日曆；人生插圖改為老公寓鐵窗與貓、榕樹下的板凳與茶壺、平溪天燈；人物大頭從 emoji 換成 7 種台灣角色（紅肚兜嬰兒、小黃帽男孩、耳下三公分繡學號女孩、機車安全帽男人、識別證上班族女人、白汗衫蒲扇阿公、燙捲髮花襯衫阿嬤）。全部是向量圖，由 `node scripts/build_art.js` 產生到 `assets/art/`。
- **出生抽選開場畫面（v6.15）**：按下「開始這一段台灣人生」後，會先依序顯示「你將出生在」與放大的出生地滾動抽選、「你將出生於」與放大的出生年份滾動抽選（若首頁已自選大區或指定年份，最後會停在你選的值），接著出現你的背景卡（姓名、性別、家庭、父母、家境、先天個性、時代氛圍），最後按「出生」才正式開始。動畫中可點「跳過動畫」、點畫面任意處或按 Enter／空白鍵直接揭曉；自動模式下動畫會加速。
- **背景音樂（v6.14）**：第一次點擊或按鍵後開始播放（瀏覽器不允許自動播放），依「Morning → Evening → Morning…」無限循環，開頭柔和淡入、換曲時交叉淡入淡出；頂部「🎵 音樂」與人生畫面工具列的 🎵 可切換靜音（會記住設定），切到其他分頁時自動淡出暫停。
- **年度重心改版（v6.13）**：重心依人生階段提供不同選項——求學時期（升學衝刺、社團與朋友、打工存錢、均衡）、工作時期（衝刺事業、工作生活平衡、省吃儉用、下班進修、陪伴家人、規律養生）、退休時期（養生、社區志工、旅行、含飴弄孫、隨遇而安）。進國中、出社會、結婚、第一個孩子、45 歲、退休與過勞時會跳出重心抉擇；效果依目前數值邊際遞減，同一重心連續超過 4 年效果開始衰退，衝刺事業連續 4 年以上可能過勞送醫；重心也會改變升遷、婚姻危機、中風機率、生活費與旅費。時間軸每三年小結一次重心帶來的變化，選單顯示連續年數與健康警示；自動模式依個性選重心。實測工作時期一直衝刺事業：45 歲年薪 +8%、60 歲資產 +13%，但平均壽命少約 3 年；規律養生壽命多約 1.7 年；省吃儉用資產多約 27%，幸福較低。
- **抉擇結果跳窗（v6.11）**：每次做完選擇，會跳出「抉擇結果」視窗，顯示你選了什麼、當下發生的事、薪資變化與這個選擇帶來的影響標籤；按下「確認，繼續人生」（或 Enter）後時間才會繼續走，避免錯過選擇的後果。
- **全面內容稽核（v6.10）**：新增 `node scripts/audit_content.js`（預設跑 20,000 段人生，`--static` 只做靜態檢查），檢查資料檔空白欄位、重複 id、效果與條件參數是否被引擎讀取、職業／地區／事件／記憶標籤的跨檔引用，以及引擎裡沒被呼叫的方法；再用自動與亂選、教學版、史實模式混合跑蒙地卡羅，確認每張抉擇卡、每個選項、每個歷史與未來事件、周圍的人與事、習俗、海外事件與時代日常都真的會出現。這次修正了「落榜重考」卡永遠被職業卡搶走、1950 年的美援與地方選舉事件因為出生年隔年才開始而永遠看不到、三張時代卡的考試加分沒有作用，並清掉沒被使用的參數與方法。目前 20,000 段人生 0 崩潰，所有內容都至少出現過一次。
- **數值更有意義、疾病與事故（v6.9）**：
  - **屬性不再頂天**：過去 30 歲後約四成人的知識與人際已達 100，之後再怎麼進修、參加社團都加不上去。改為邊際遞減（50 分時全額、80 分約五成、95 分約兩成），高齡後知識與人際也會慢慢流失；現在 30–60 歲幾乎沒有人頂天，每個選擇的數值變化都看得見。
  - **屬性門檻**：44 個選項加上健康、知識、人際或心情門檻，例如出國念研究所需知識 65、簽志願役需健康 55、加入扶輪社需人際 55、心情太低落時無法開始一段感情；門檻不足時選項會鎖住並寫明「需 X，目前 Y」。
  - **疾病與事故**：依台灣交通事故、職業災害、中風與癌症發生率，每年都可能遇上意外或疾病，結果可能是康復、輕度或重度失能，或當年過世；1950–1966 年出生的孩子可能感染小兒麻痺。癌症確診後會進入治療抉擇。
  - **失能的長期影響**：輕度失能健康上限 75、不能再做重體力工作；重度失能健康上限 48、不能從事勞力與久站工作，原本做這些工作的人會失業重找工作或轉任輕便職務，也會鎖住需要體力的人生選項。實測約一成的人生會留下輕度失能、約一成留下重度失能（多發生在老年中風）。
- **周圍的人與事（v6.8）**：新增 45 則好友、親戚、鄰里與城市變化的敘事事件（👥 好友、👪 親戚、🏘 鄰里），例如好友出國讓你寂寞、表哥年紀輕輕就走了、家附近蓋了商場或捷運、鎮上的工廠搬走、阿姨生病後說「身體只有一個」。這些事件不改變屬性，但會留下記憶；日後遇到相關抉擇（健檢紅字、北漂、外派、作保、投資陷阱、創業、生育、長照、退休等）時，決策卡會出現「💭 你想起…」，自動模式也會略微受影響。實測每段人生約遇到 16 則周圍的人與事，約有 3 到 4 次抉擇會想起過去的事。
- **看得見的選擇後果（v6.7）**：每次抉擇前後都會比對健康、幸福、知識、人際、淨資產、月薪，以及工作、居住地、婚姻、子女、房子、學歷的變化，選完立刻在畫面提示，時間軸上的抉擇也附上「這次選擇的影響」小標籤；時代卡多年後的「時代的回聲」會點名當初的選擇並顯示後來的影響。訃聞新增「⚖️ 改變你人生的關鍵選擇」，挑出影響最大的五個選擇，列出當下與後來的影響，以及「🔀 沒走的路」，鼓勵下一局換條路試試。
- **每一局都不一樣：隱藏世界線與重玩多樣性（v6.6）**：
  - **隱藏的未來世界線**：每段人生在 2026 年後會抽出一條看不到的世界線，五個面向各自分岔：AI 快速普及或趨緩、氣候穩定或極端、經濟繁榮／停滯／危機、兩岸和緩或緊張、生育回升或人口萎縮。世界線決定哪些未來事件比較可能發生，也左右 2027 年後的股市、房市、薪資走勢，以及未來抉擇卡的成敗機率。訃聞最後才揭曉「🔮 你走過的未來世界線」。
  - **背不起來的未來**：未來事件從 30 個增加到 58 個（涵蓋 2030–2125 年），包含互斥的分岔（AI 泡沫破裂或生產力紅利、準封鎖或局勢和緩、全球衰退或新興市場繁榮、人口跌破 1,500 萬或回聲嬰兒潮等）；未來卡新增 8 張中晚年抉擇（股災、局勢緊張時的退路、孩子移民、氣候遷徙、抗老療程、誰來照顧你、數位分身、中年轉職），未來卡的選項有八成以上要依屬性、性格與世界線擲骰決定結果。
  - **重玩檢測**：新增 `node scripts/variety_report.js`（快速版加 `--quick`），量測各年代開局的抉擇與事件密度、成年後最長的空白期、未來事件在不同人生之間的重疊度，以及同年同地區出生者在職業、資產、壽命與抉擇路徑上的分散程度，未達標時以結束碼 1 結束。目前兩段 2026 後的人生，未來事件組合平均只重疊約四分之一；同年同地區出生的兩段人生，抉擇路徑平均只重疊不到兩成。
- **2000 年後出生的時代卡（v6.5）**：補上新世代的童年到青年期，共 58 張卡。
  - 父母代選：平板育兒、雙語幼兒園還是公幼。
  - 自己選：十二年國教會考志願（明星高中、技職、實驗教育）、2021 停課不停學、學習歷程要不要請顧問、網紅與電競夢、背著學貸出社會（新增學貸效果）、2017 與 2021 加密貨幣熱潮、養毛小孩還是生小孩、新住民第二代要不要學媽媽的母語。
  - 實測各年代出生者一生自己做的時代卡平均都在 3 到 4 張之間，2000 年後出生者另有約 1 張由父母代選。
- **時代日常與未來抉擇（v6.4）**：
  - 抉擇卡分成三級：🕰 時代大事、🧭 時代日常、🔮 未來，共 48 張，訃聞與時間軸都會標出等級。
  - **🧭 時代日常（13 張）**：不綁大事件，而是那個年代的社會期待與生活趨勢下會遇到的選擇，例如「女孩子念到高中就夠了」、婚育後辭職回家（男主外女主內）、被期待一肩扛起家計、三代同堂、傳宗接代的壓力、標會、跑遠洋漁船、考公職鐵飯碗、網拍創業、責任制加班、下班兼外送、存股還是存頭期款、凍卵、幫兒女帶孫。
  - **🔮 未來卡（13 張，虛構推演）**：多數要先發生對應的「台灣未來預測」事件才會出現，例如週休三日後多出來的星期五、40°C 下的戶外工作、社宅、半導體轉往生醫綠能、精準醫療檢測、延退至 70 歲、轉型津貼、台流出海、全息遠距後搬回家鄉；另有不綁事件的趨勢卡：AI 伴侶、少子化併校、百歲人生理財、一人戶共居宅。
  - 補上 1996 台海飛彈危機。
  - 實測（自動模式）每段人生平均遇到 3 到 4 張，只有約 6% 一張都沒遇到；1950 年代出生以時代大事與日常為主，2000 年後出生以未來卡為主。
  - 新增條件：已婚、子女數與子女年齡、與父母同住、配偶是否工作、是否有房、是否北漂、低薪、已發生的未來事件；新增效果：辭職顧家數年後二度就業、配偶辭職、搬出去住、想生的孩子數、凍卵提高高齡受孕率、放棄大學聯考、夜間部補學歷、延後退休、搬回家鄉等。
- **時代抉擇卡與性格的長期影響（v6.3）**：
  - **不同年代，不同的抉擇**：新增 20 張「時代抉擇卡」（`data/tw_decisions.json` 的 `era_choices`），每張綁定一段年份，只有那個年代、那個年紀、符合身分條件的人才會遇到：耕者有其田、眷村、客廳即工廠、長子長女休學供弟妹、退出聯合國後的移民潮、一卡皮箱走天下、大家樂、台股萬點、開放大陸探親、台商西進、竹科分紅配股、跨國婚姻、現金卡、22K、澳洲打工度假、太陽花、低薪出走、台積電海外廠外派、AI 浪潮。
  - **依條件觸發，不是人人都有**：可限定省籍、家境、地區、職業、學歷、排行、手足數與存款；性格會放大或降低出現機率（例如冒險投機者更容易碰上大家樂與現金卡）。實測 1950 年代出生平均遇到約 2 張、1980 年代約 0.9 張；整體約一半的人一張都不會遇到。2000 年後出生者目前只會碰到 AI 浪潮與外派等少數卡，2030 年後的未來卡尚未加入。
  - **後果會延後揭曉**：選項的成敗依屬性與性格擲骰，部分後果在多年後才以「🕰 時代的回聲」出現，例如 1970 年代換的美金在新台幣升值後縮水、台商在 2008 年後的關廠潮、竹科分紅在 2008 年費用化。
  - **省籍與排行**：出生時抽出閩南、客家、外省、原住民或新住民家庭（依出生年與地區比例），以及在手足中的排行。
  - **性格的長期牽引**：七種性格會左右自動模式的既有抉擇（北漂、轉職、外派、股災、長照、退休等）、每年小幅影響四維屬性，拼命三郎與知識高的人較常升遷；健康過差時會常請病假、收入打折。
  - 訃聞新增「🕰 你遇上的時代」，列出這一生遇到的時代抉擇與當時的選擇。
- **家庭與生命歷程重整（v6.2）**：
  - **先選擇、再領薪**：畢業抉擇後直接接續兵役或選職業，系統不會先派工作；轉職可重複發生，並由裁員、返鄉、役期屆滿等契機觸發。
  - **真實的另一半與父母**：伴侶有姓名、年齡、工作與收入，會分手、退休、離世；父母各自老去，遺產由手足分配。結婚後資產合併計算；離婚時婚前財產各自保留，婚後累積的財產依兩人收入貢獻比例分配。
  - **史實模式**：預設成為重大事件當事人的機率很低，只有個性、居住地與經歷吻合時才明顯升高（例如冒險投機者約為謹慎者的三倍）。
  - **生育可延後或停止**：「今年先不要」與「不再生」分開，並依女方年齡計算受孕機率。
  - **退休**：依出生年與職業決定請領年齡，年金與年資、薪資連動，受僱者 72 歲前必退休。
  - **學群細分**：醫學／牙醫、護理藥學醫技、法律、商管會計、人文藝術、電資理工、公費七類；律師、會計師須通過專技高考。
  - **1968 年前的初中考制**：國小畢業先考初中或初職，15 歲才考高中、高職。
  - **天災依受災率發生**：每戶只擲一次，未受災者不會被迫搬遷。
  - **留學與債務**：父母資助、自有資金、留學貸款分開計算；債務有借款上限，不再無限複利。
  - **歷史事件全部為單一年度卡片**（85 張），餘波只顯示到玩家所在年份。
- **各職業年齡資產曲線與世代漏斗校準（v6.1）**：
  - **史實模式雙軌制與時空解耦**：區分「系統性事件」與「單點偶發慘劇」（`incident` 終生上限 1 次、單次低機率），補齊 `east_origin_or_resident` 硬門檻；將跨年拼盤事件（2008 金融海嘯 vs 2009 莫拉克、2014 北捷 vs 2016 小燈泡、2025 vs 2026）全面拆卡，並將經濟衝擊與「顯示所有歷史事件」開關完全解耦。

- **嚴格因果順序、年齡分流與防時代錯亂**：
  - 感情與家庭採嚴格因果鏈：交往（`D17B`）→ 結婚（`D18`）→ 選擇是否生育（`D19`）→ 育兒教育與子女留學（`D21`／`D29`／`cust_postpartum`），未生育不會觸發子女相關事件。

## 四、快速啟動與部署方式

### 1. 本機直接離線運行
解壓縮後直接雙擊 `index.html` 即可遊玩（透過 `data/tw_bundle.js` 離線載入全部 13 份資料庫）。

### 2. 本機靜態伺服器預覽（開發模式）
```bash
python3 -m http.server 8000
# 瀏覽器開啟 http://localhost:8000/
```

### 3. 修改 JSON 後同步離線資料庫
每次編輯任何 `data/tw_*.json` 後，請務必在專案根目錄執行：
```bash
python3 sync_data.py
```
腳本會將全部 **13 份 JSON** 打包同步至 `data/tw_bundle.js`，確保 `file://` 雙擊開啟與線上環境資料一致。

### 4. 用 Excel 審閱與修改事件
```bash
pip install openpyxl
python scripts/events_excel.py export             # 產生 review/tw_events_review.xlsx
python scripts/events_excel.py import --dry-run   # 改完 Excel 後先看會改哪些欄位
python scripts/events_excel.py import             # 寫回 data/tw_*.json 並自動重建 tw_bundle.js
python scripts/events_excel.py roundtrip          # 驗證「匯出後原樣匯回」零差異
```
Excel 收錄歷史事件、當事人結果、未來推演、決策卡與選項、人生階段事件、同儕插曲、習俗、時代日常、教育插曲、留學事件、回流觸發、時代抉擇卡與選項、天災機率共 17 個可編輯分頁，欄位依「識別／觸發條件／機率／影響／內容」上色分組；用法寫在檔案的「說明」分頁。另有一個唯讀分頁列出寫死在 `js/tw_engine.js` 的機率判定，改了不會匯回。

### 5. GitHub Pages 部署
專案已內建 `.nojekyll` 且全部資源皆採 `./` 相對路徑，直接將專案根目錄檔案推送至 GitHub Pages 分支（如 `https://<user>.github.io/<repo>/`）即可運作。
