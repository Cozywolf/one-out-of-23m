# 生在台灣（v5.8）· 2,340 萬分之 1 台灣人生模擬

> 參照 [1in8b.life](https://1in8b.life/) 模擬精神與 [rollroyces/born-somewhere](https://github.com/rollroyces/born-somewhere) 架構改編，專注於 **台灣六大區域 × 跨年代（1950–2110+）** 的微觀人生模擬器。

線上試玩：[https://cozywolf.github.io/one-out-of-23m/](https://cozywolf.github.io/one-out-of-23m/)

## 一、簡單遊玩說明

1. **決定開局條件**：在首頁選擇「台灣六大區」抽籤方式（依出生率隨機、依人口比隨機或自選大區）與「出生年代」（1950–2026 隨機或指定年份），點擊 **「開始這一段台灣人生 →」** 即可出生。
2. **控制時間流速**：
   - 頂部工具列可切換 **1×～16×** 播放速度、點擊 **`+1歲`** 逐年手動推進，或隨時按鍵盤 **空白鍵（Space）** 暫停／繼續。
   - 若想快速觀察多段人生走向，可開啟 **「自動：開」** 由系統自動代選抉擇；也可隨時點擊 **「戶口卡」** 檢視出生證明或匯出 PNG 紀念卡。
3. **做出人生抉擇與調整重心**：
   - 遇到升學、選系、兵役、北漂、買房、婚育、股災、天災或長照等關鍵節點時，系統會自動暫停並彈出決策卡，同時附上 **「📊 時代趨勢」** 統計背景供參考。
   - 左欄下方可隨時調整 **「年度重心」**（均衡生活、全力學習、衝刺工作、省吃儉用、規律養生、陪伴家人），影響每年四維屬性與儲蓄率。
4. **閱讀時間軸與時代脈絡**：
   - **左欄**：身分資料、四維狀態（健康／幸福／知識／人際）、**目前薪資與本年收支**、**總淨資產（現＋股＋房）** 及當前生效的台灣制度。
   - **中欄**：時間軸即時呈現日常切片、**台灣歷史現場**（點擊標題可展開詳情與次層「後世餘波」）、**周圍人的身影**微故事，以及 2027 年後的 **台灣未來預測**。
   - **右欄**：可點擊互動的台灣六大區地圖、4 位同年出生對照同伴、區域 vs 全台存活曲線，以及百歲人生方格。

## 二、起始設定說明（三大開關）

首頁「事件呈現與風險模式」列提供三個可自由切換的起始選項，決定這段人生的資訊密度與風險強度：

| 起始選項 | 預設狀態 | 功能與影響說明 |
| --- | --- | --- |
| **📢 重大惡性社會事件** | **開啟** | 控制是否呈現台灣重大刑案、公安意外與敏感創傷事件細節。**關閉時**會切換為「教學友善模式」（亦可用網址參數 `?edu=1` 直接啟動）：隱藏個人自殺與創傷細節、重大社會刑案改僅呈現「法制與制度改革重點」，且會自動鎖定並關閉「史實模式」。 |
| **⚡ 史實模式** | **關閉** | 僅在「重大惡性社會事件：開啟」時可進一步啟用。**開啟後**，主角會依先天個性、學經歷與所在大區，有機率直接成為重大天災、金融風暴或社會事件之「當事人」，可能面臨鉅額財務損失、長期健康受創，甚至觸發致命結局。 |
| **📚 顯示所有歷史事件** | **關閉** | 控制「台灣歷史現場」卡片的出現頻率。**關閉時（預設）**，系統每 **2–3 年** 才會在當年度符合條件的歷史事件中隨機抽選 **1 則** 顯示，避免事件連發造成資訊過載；**開啟時**，則會完整顯示所有符合當年度與地區條件的台灣歷史事件。 |

## 三、核心特色與系統機制

- **0 歲零個人資產與先扣生活費再結算股市**：出生不再自帶個人存款；6 歲後依家境與打工／建教狀態累積小額零用金，滿法定成年年齡（2023 年前 20 歲、2023 年起 18 歲）才解鎖台股定期定額。每年先結算「收入 － 當代生活總支出（含房租／房貸、子女、長照、稅賦與生活升級）」，現金不足時先強制賣股支應生活開銷，再對剩餘持股套用當年度台股報酬。
- **常駐薪資與關鍵抉擇變化追蹤**：左欄常駐顯示名目月薪／年薪（含 2025 購買力）與年度收支結餘；每次做出影響薪資的關鍵抉擇（如選系、考研、北漂、返鄉、降薪顧健康）皆即時計算並顯示月薪或起薪倍率變動。
- **全面防未來年份劇透**：決策選項全面採年代分流文案（如 2023 年前不出現新青安、2003 年前不出現 0050、2007 年前不出現高鐵），歷史事件的「後世制度與社會餘波」改為次層預設收合。
- **周圍人的時代側影（1in8b.life 風格）**：隨年代與年齡偶爾穿插身邊同學、親友與鄰居的日常切片，呈現單一角色之外的同代人處境。
- **台灣未來預測（2027 年起）**：比照「台灣歷史現場」三段式折疊卡，透過世界旗標與互斥平行分支隨機且符合邏輯地推演未來台灣，並實際影響玩家薪資、持股、房產估值、健康與生活費。

## 四、快速啟動與部署方式

### 1. 本機直接離線運行
解壓縮後直接雙擊 `index.html` 即可遊玩（透過 `data/tw_bundle.js` 離線載入全部 13 份資料庫）。

### 2. 本機靜態伺服器預覽（開發模式）
```bash
python3 -m http.server 8000
# 瀏覽器開啟 http://localhost:8000/
```

### 3. 修改 JSON 後同步離線資料庫
每次編輯任何 `data/tw_*.json` 後，請務必在專案根目錄執行：
```bash
python3 sync_data.py
```
腳本會將全部 **13 份 JSON** 打包同步至 `data/tw_bundle.js`，確保 `file://` 雙擊開啟與線上環境資料一致。

### 4. GitHub Pages 部署
專案已內建 `.nojekyll` 且全部資源皆採 `./` 相對路徑，直接將專案根目錄檔案推送至 GitHub Pages 分支（如 `https://<user>.github.io/<repo>/`）即可運作。

### 各資料庫重點欄位與設計說明

1. **`data/tw_regions.json`**：將台灣劃分為雙北基、桃竹苗、中彰投、雲嘉南、高屏、宜花東與離島六大區，定義出生權重、人口比、區域平均壽命偏移值、家戶所得倍數、房價所得比、產業結構與青年跨區遷徙機率，並納入家戶所得五等分位（Q1–Q5）。
2. **`data/tw_eras.json`**：透過 18 組年代錨點（1950–2070）線性插值並結合 36 個關鍵年份覆寫（如 1974 石油危機、1990 股災、2009 金融海嘯），驅動全遊戲的物價指數（CPI）、平均月薪、基本工資、定存利率、大學錄取率、總生育率與 26 項台灣制度開關（如 1950 勞保、1968 九年國教、1987 解嚴、1995 健保、2005 勞退新制、2019 同婚、2023 新青安）。
3. **`data/tw_lifetable.json`**：以內政部簡易生命表與衛福部死因統計為基準，結合年代死亡率倍率、年齡段死亡率、性別與區域修正、癌症／事故／颱風地震風險，以及台灣 24 小時求助專線清單。
4. **`data/tw_events_history.json`**：完整涵蓋 1950 年美援與地方自治至 2026 年超高齡與 AI 狂潮共 56 起事件；每筆皆含 `summary`、`institutional_aftermath`、`gameplay_impact`、`sources`、`cultural_footnote_en`，重要事件另附 `protagonist_involvement` 供「史實模式」演算當事人機率與後果。
5. **`data/tw_decisions.json`**：收錄 `D01`–`D30` 共 29 張本土關鍵抉擇卡（含一卡四劇本的時代金融陷阱 `D14`、消債更生 `D28`、子女留學 `D29`、危機賣房 `D30`）與 5／15／30／50／70 歲暫停反思提問；選項支援 `era_labels` 年代分流文案與嚴格財力／屬性資格檢核。
6. **`data/tw_life_stages.json`**：定義高中聯考（1954–2000）、國中基測（2001–2013）與國中會考（2014+）的成績落點門檻，以及 `LS01`–`LS10` 涵蓋童年到退休的 10 個環境養成事件，連動後續升學、打工收入與職涯加成。
7. **`data/tw_education_careers.json`**：切分戰後聯考、五專補習潮、410 教改與 108 課綱四大教育時期，並提供 15 種具時代特色的台灣職業（如加工區女工、中小企業老闆、竹科工程師、軍公教、醫師、外送員等）與薪資／健康參數。
8. **`data/tw_culture_eras.json`**：提供四個時代的家庭性別觀、理財習俗與跨海通訊載體（航空信 → 越洋電話 → MSN／Skype → 即時視訊），以及 5 項台灣生活習俗（如坐月子、標會、普渡）與 7 種先天個性特質。
9. **`data/tw_names.json`**：依台灣前十大姓氏權重與 6 個出生世代（1950s 至 2020s）常見男女命名語料庫，自動生成貼合時代感的主角、父母與同年同伴姓名。
10. **`data/tw_market_history.json`**：完整收錄 1962–2026 年共 65 年的台灣股市年漲跌幅、盤中最大回撤、殖利率與房價年增率，並定義定存／指數 ETF／融資槓桿三種投資風格，以及 2027 年後經過千次蒙地卡羅校準的長期報酬參數（名目約 6.2% 含息＋10% 景氣回檔）。
11. **`data/tw_study_abroad.json`**：收錄公費留考、自費深造、小留學生、交換生、打工度假、職場轉軌等 6 條留學路徑，以及美、日、澳、英、加、德 6 國的年代事件與薪資生活費倍率，搭配 12 項思鄉／政策返台契機與 `D27` 海歸抉擇。
12. **`data/tw_ambient_peers.json`**：收錄 26 則 1950–2080s 的身邊親友微故事（如九年國教前輟學女同學、移居國外寄丟航空信的小學好友、因性別被迫改念護理的高中摯友、22K 室友、北漂返鄉好友），每則均依年代與年齡區間自然觸發，絕不外洩未來年份。
13. **`data/tw_future_forecasts.json`**：2027–2110 年的 26 則「台灣未來預測」虛構推演，涵蓋 AI 辦公轉型、矽盾 2.0 vs 晶圓去中心化、深層地熱 vs 電價陣痛、新移民永居 vs 延退 70 歲、mRNA 癌症疫苗、失智基因療法、空間運算終結北漂與百歲人生，確保每場模擬隨機卻前後自洽。

## 七、分級與資料聲明（15+）

本模擬器依據內政部生命表、主計總處家庭收支與薪資調查、衛福部死因統計、教育部升學統計、國發會人口推估與臺灣證券交易所公開資料編製，模擬結果為統計演繹與情境推演，非真實人物紀錄亦非投資建議。

若你或身邊親友正處於情緒低潮、暴力或詐騙壓力，台灣 24 小時免費求助資源：
- **1925** 安心專線 ｜ **1995** 生命線 ｜ **113** 婦幼保護專線 ｜ **165** 反詐騙專線
