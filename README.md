# 生在台灣 · One out of 23M（v5.4.1）

> 參照 [1in8b.life](https://1in8b.life/) 模擬精神與 [rollroyces/born-somewhere](https://github.com/rollroyces/born-somewhere) 架構改編，專注於 **台灣六大區域 × 跨年代（1950–2110+）** 的微觀人生模擬器。

線上試玩：[https://cozywolf.github.io/one-out-of-23m/](https://cozywolf.github.io/one-out-of-23m/)  
教學防雷版（預設關閉重大惡性社會事件）：`https://cozywolf.github.io/one-out-of-23m/?edu=1`

---

## 一、專案特色

* **純靜態零後端架構**：採用 Vanilla HTML / CSS / JavaScript，邏輯引擎（`js/tw_engine.js`）與介面渲染（`js/tw_ui.js`）分離；解壓縮後雙擊 `index.html` 即可離線遊玩，亦相容 GitHub Pages 靜態託管。
* **六大區域 × 跨年代真實數據**：以雙北基、桃竹苗、中彰投、雲嘉南、高屏、宜花東與離島為空間切分，結合民國／西元雙軌時間軸，並以歷年 CPI 同步換算「當年度名目金額」與「折合 2025 年購買力」。
* **貼近現實的財務與薪資模型**：
  * 0 歲零個人存款，6 歲起依家境與打工狀況累積零用金，滿法定成年年齡（2023 年前 20 歲、2023 年起 18 歲）才解鎖個人台股投資。
  * 年度收支先扣除生活費、房租／房貸、子女養育與長照開銷，現金不足時強制賣股變現，再對剩餘持股套用史實台股大盤報酬率。
  * 左欄常駐月薪／年薪與收支結餘，並追蹤每一次關鍵抉擇（選系、考研、北漂、返鄉、晉升等）對薪資的實際影響。
* **多層次事件與教育設計**：
  * **台灣歷史現場**：採「中立事實 → 後世制度與社會餘波（次層折疊防劇透） → 資料出處」三段式結構，附英文文化註解、教學防雷開關（`?edu=1`）、「顯示所有歷史事件」節奏開關（預設關閉，每 2–3 年隨機顯示 1 則），以及需手動確認警語的「史實當事人模式」。
  * **周圍人的時代側影**：參照 1in8b.life 設計，偶爾在時間軸穿插身邊同學、親友與鄰居的時代微故事。
  * **台灣未來預測（2027–2110）**：透過世界線旗標、互斥平行分支與因果前置依賴，隨機且前後自洽地推演未來台灣事件並影響角色命運。
* **視覺化圖表與本機保存**：內建存活曲線 SVG（所屬大區 vs 全台平均）、5 面向終身軌跡圖、互動式六大區地圖、Lab 批次統計實驗室、本機書架與追思館，以及離線 Canvas 2D 高解析度 PNG 戶口出生卡／生命證書匯出。

## 二、快速啟動與維護方式

### 1. 本機直接遊玩（無需安裝任何套件）
直接下載並解壓縮專案，用瀏覽器雙擊開啟根目錄的 `index.html` 即可（系統會於 `file://` 協議下自動退回讀取 `data/tw_bundle.js`）。

### 2. 本機伺服器開發模式
若使用本機靜態伺服器（如 `python3 -m http.server 8000`）或部署至 GitHub Pages（`https://`），瀏覽器會直接透過相對路徑 `./data/tw_*.json` 即時讀取 JSON 檔案。

### 3. 修改 JSON 後同步離線包
編輯 `data/` 底下任何一份 `.json` 後，於專案根目錄執行：

```bash
python3 sync_data.py
```

腳本會自動將全部 13 份 JSON 打包更新至 `data/tw_bundle.js`，確保雙擊 `index.html` 的離線模式也能載入最新資料。

### 各資料庫詳細介紹

#### 1. `data/tw_regions.json`（空間維度）
定義台灣六大區域（`north_taipei` 雙北基、`north_hsinchu` 桃竹苗、`central` 中彰投、`south_tainan` 雲嘉南、`south_kaohsiung` 高屏、`east_islands` 宜花東與離島）的空間統計與生活語料：
* 涵蓋縣市清單、2025 人口占比與出生抽籤權重。
* 區域平均壽命修正係數（反映如雙北與花東的壽命落差）、家戶所得倍數、房價所得比與農／工科／服務產業權重。
* 青年外移率（`out_migration_rates`，驅動北漂與跨區就業機制）及各地氣候、通勤與在地文化標籤，同時供右欄互動式 SVG 地圖統計卡讀取。

#### 2. `data/tw_eras.json`（時間維度與制度開關）
以西元 1950 至 2070 年（超過 2070 年由引擎自動複利外推）為軸，建構台灣戰後至未來的宏觀環境：
* **年代錨點與內插**：存放歷年 CPI 指數、基本工資、平均月薪、失業率、大學錄取率、總生育率與利率；另設 `year_overrides` 精準覆寫特定年份衝擊（如 2009 年 22K 定錨與高失業率）。
* **18 項台灣特有制度開關（`institutional_switches`）**：包含 1968 九年國教、1987 解嚴、1995 全民健保、2001 基測、2005 勞退新制、2014 會考、2019 同婚專法、2022 私校退場等，實際左右醫療自付額、退休金替代率與升學規則。
* **男性兵役沿革（`conscription_rules_male`）**：依出生年次切換 3 年、2 年、1 年、4 個月與 2024 年恢復 1 年役期。

#### 3. `data/tw_lifetable.json`（生存引擎與死因矩陣）
負責驅動模擬器的逐歲生死判定與統計校準：
* 按年代與性別提供各年齡組別的年度死亡機率 $q_x$，計算時再結合區域壽命係數、健康值、健保開關與未來醫療突破倍率。
* 內建年齡別主要死因權重（如青壯年機車交通事故、中壯年癌症、高齡心血管與失智相關疾病）；在教學防雷模式（`?edu=1`）下會自動將自殺死因權重歸零。
* 收錄台灣常見天災（颱風、強震）與流行病學生活習慣風險因子。

#### 4. `data/tw_names.json`（台灣各世代姓名庫）
參照內政部姓名統計設計，讓不同年代出生的角色與同伴擁有自然且符合時代的姓名：
* 收錄台灣前十大姓氏加權分布（陳、林、黃、張、李、王、吳、劉、蔡、楊）與其他常見姓氏池。
* 按出生年代（1950s 至 2020s）區分男女常見名字庫，呈現從「淑芬／志明」、「怡君／家豪」到「詠晴／宇恩」的世代命名演變。

#### 5. `data/tw_events_history.json`（台灣歷史現場）
收錄 1950 年代至 2026 年共 **37 起** 台灣指標性歷史、財經、天災、疫情與重大社會法制事件：
* 每筆事件皆包含中立事實描述、後世制度與社會餘波（`aftermath`）、官方資料出處與英文文化註解（`cultural_footnote_en`）。
* 區分新聞可見區域（`regions`）與實際受災區域（`impact_regions`），避免非災區角色誤觸重建抉擇。
* 標記 `sensitive` 欄位供教學防雷模式過濾創傷細節（保留公民制度改革重點），並為「史實當事人模式」提供高風險事件捲入參數。

#### 6. `data/tw_decisions.json`（台灣本土關鍵決策卡）
收錄 **D01–D26** 共 26 張橫跨求學、職涯、財務、家庭與高齡危機的核心決策卡：
* 涵蓋升學分流、選系、重考、兵役（含 1999 年前大專預官與 2000 年後國防役／研發替代役）、畢業出路、北漂與返鄉、無薪假、買房、金融吸金與投資詐騙（`era_variants` 依年代切換鴻源、雙卡、連動債或飆股群組，並採延遲至史實崩盤年結算）、1995 健保前後重病費用、婚育、長照風暴與善終自主。
* 全面導入年代分流文案（`era_labels`），確保不會在尚未實施的年份提前出現未來名詞（如 2023 年前不出現新青安、2003 年前不出現 0050）。

#### 7. `data/tw_life_stages.json`（全人生時期環境養成與大考規則）
補足各求學與生活階段的日常環境互動（**LS01–LS10**）與升學大考機制：
* **國中升學大考規則**：依年份自動切換初中聯考、高中五專聯考、基測與會考，綜合角色知識值、家境與重心擲骰落點，動態鎖定未達標的明星高中／普通高中志願。
* **各階段環境事件**：涵蓋國小課後（補習／校隊／家務）、普通高中選組、高職五專考證照／建教實習、大學玩社團／進教授實驗室／打工家教／企業實習／提前備考公職、職場管理職與證照進修，以及退休後的社區大學與含飴弄孫，並累積為角色專屬「養成能力與經歷」徽章。

#### 8. `data/tw_education_careers.json`（教育資源與職涯薪資）
整理 1950–2026 年台灣教育體制與勞動市場結構：
* 記錄各年代的學制特性、影子教育（補習班與才藝軍備賽）與城鄉／階級教育落差。
* 提供各產業（科技電資、製造傳產、金融商管、軍公教、醫療照護、文創服務與農林漁牧等）在不同年代與區域的職缺稱謂與薪資倍率基礎。

#### 9. `data/tw_culture_eras.json`（各年代文化與社會氛圍）
為時間軸注入不同世代的台灣生活感與集體記憶：
* 依年代收錄家庭觀念（如傳統重男輕女、雙薪小家庭、頂客與一人戶）、節慶習俗、大眾娛樂與街頭生活氛圍。
* 在角色成長的平淡年份裡提供具時代特色的日常旁白，與重大歷史新聞形成冷暖對照。

#### 10. `data/tw_study_abroad.json`（出國留學與海歸回流系統）
支援角色離開台灣赴海外求學與工作，同時維繫與台灣的連結：
* 收錄留學出發契機（獎學金、公費、交換、打工度假與海外研究所等），並針對台灣最常前往的留學國家整理各年代可能遭遇的當地事件、薪資與生活費倍率。
* 旅外期間持續推播「跨海台灣快訊」，並透過父母年邁、台灣大選、產業轉型或重大制度改革等事件，觸發 **返台或留外抉擇（`D27`）**。

#### 11. `data/tw_market_history.json`（台股與金融市場歷史行情）
驅動角色投資部位的真實市場波動：
* 記錄歷年台灣加權股價指數年漲跌幅（`price_pct`）與現金股利殖利率（`div_yield`），真實還原 1987–1990 萬二狂潮與崩盤、1997 亞洲金融風暴、2000 網路泡沫、2008 金融海嘯、2020 疫情反彈與近年 AI 行情。
* 與角色理財風格（定存、定期定額大盤、開槓桿）連動，在大幅回檔年度觸發融資追繳或恐慌賣出抉擇。

#### 12. `data/tw_ambient_peers.json`（周圍人的時代側影）
參照 1in8b.life「偶爾浮現身邊他人命運切片」的設計，收錄 **20 則** 橫跨 1950–2070s 的同代人微故事：
* 透過國小同班同學、高中好友、大學室友、外派表哥、菜市場阿姨與公園球友的遭遇（例如早年女童失學、女生想念電機卻被要求改念護理、小學摯友移民靠航空信漸行漸遠、2009 年室友領 22K 住頂加等），映照單一主角以外的台灣社會結構。
* 每則皆設定觸發年份區間與年齡區間，由引擎依冷卻間隔低干擾穿插於時間軸，並視情況附上不含未來劇透的當代背景註記。

#### 13. `data/tw_future_forecasts.json`（台灣未來預測，2027–2110）
當角色活過 2026 年後啟動，沿用「台灣歷史現場」三段式折疊卡片格式（並以靛藍／青綠視覺徽章與「虛構推演」註記明確區隔於真實歷史），收錄 **26 則** 邏輯推演事件：
* **三大互斥平行分支**：每段人生隨機走入其一，確保世界線前後自洽——① 半導體命運（矽盾 2.0 vs 晶圓去中心化轉型）、② 能源路徑（深層地熱潔淨基載 vs 算力搶電電價大漲）、③ 缺工解方（新移民永居法 vs 彈性延退至 70 歲）。
* **五組因果前置依賴**：如 AI 代理進駐職場後才可能觸發算力稅／UBI 試點或全息協作終結北漂；酷暑常態化後才觸發沿海海綿城市改造；mRNA 癌症疫苗納入健保後才觸發器官再生與百歲健康人生。
* 所有未來預測皆實際連動玩家數值（產業薪資、持股估值、房產漲跌、租金、長照費、健康與死亡率）。
