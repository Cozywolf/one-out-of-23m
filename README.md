# 生在台灣 v5.2 · 台灣人生模擬（GitHub Pages × 手機響應式優化版）

純靜態前端、零後端相依，整合 **11 份台灣統計、史實台股房市、教育職涯、留學海歸、階段養成與史實當事人資料庫**，同時支援**本機雙擊離線遊玩**與 **GitHub Pages 手機／電腦線上託管**。

## 放上 GitHub Pages（3 分鐘完成）
1. 建立一個新的公開 GitHub 儲存庫（例如 `born-in-taiwan`）。
2. 將本資料夾內**所有檔案與子資料夾**（含 `index.html`、`.nojekyll`、`LICENSE`、`assets/`、`data/`、`js/`）上傳到儲存庫根目錄。
3. 到儲存庫 **Settings → Pages → Deploy from a branch**，選擇 `main` 與 `/ (root)` 儲存，約 1–2 分鐘即可透過 `https://<你的帳號>.github.io/<儲存庫>/` 用手機或電腦開玩（網址加 `?edu=1` 預設關閉重大惡性社會事件）。

## v5.2 手機版面與操作優化
* **解決雙層置頂列遮擋**：將主導覽列改為自然捲動，讓年齡讀秒進度條與倍速控制列平順吸頂且零重疊。
* **手機 3 分頁底部導覽列（`<= 768px`）**：一鍵切換「`📜 人生與歷史`（預設首屏免滑動）」、「`👤 狀態與資產`」、「`🗺 地圖與圖表`」，並支援 iPhone 底部安全區（`safe-area-inset-bottom`）。
* **手機頂部精簡狀態條**：在閱讀事件流時同步一覽地點、健康、幸福與總淨資產。
* **觸控與彈窗優化**：針對手機微調字級與按鈕觸控面積、防止 iOS 雙擊誤縮放、決策彈窗改為底部抽屜式且可內捲動，並內建 `.nojekyll` 與 PWA 主畫面中繼標籤。
