# 生在台灣（v6.1）· 2,340 萬分之 1 台灣人生模擬

> 參照 [1in8b.life](https://1in8b.life/) 模擬精神與 [rollroyces/born-somewhere](https://github.com/rollroyces/born-somewhere) 架構改編，專注於 **台灣六大區域 × 跨年代（1950–2110+）** 的微觀人生模擬器。

線上試玩：[https://cozywolf.github.io/one-out-of-23m/](https://cozywolf.github.io/one-out-of-23m/)

## 一、簡單遊玩說明

1. **決定開局條件**：在首頁選擇「台灣六大區」抽籤方式（依出生率隨機、依人口比隨機或自選大區）與「出生年代」（1950–2026 隨機或指定年份），點擊 **「開始這一段台灣人生 →」** 即可出生。
2. **控制時間流速**：
   - 頂部工具列可切換 **1×～16×** 播放速度、點擊 **`+1歲`** 逐年手動推進，或隨時按鍵盤 **空白鍵（Space）** 暫停／繼續。
   - 若想快速觀察多段人生走向，可開啟 **「自動：開」** 由系統自動代選抉擇；也可隨時點擊 **「戶口卡」** 檢視出生證明或匯出 PNG 紀念卡。
3. **做出人生抉擇與調整重心**：
   - 遇到升學、選系、兵役、北漂、買房、婚育、股災、天災或長照等關鍵節點時，系統會自動暫停並彈出決策卡，同時附上 **「📊 時代趨勢」** 統計背景供參考。
   - 左欄下方可隨時調整 **「年度重心」**（均衡生活、全力學習、衝刺工作、省吃儉用、規律養生、陪伴家人），影響每年四維屬性與儲蓄率。
4. **閱讀時間軸與時代脈絡**：
   - **左欄**：身分資料、四維狀態（健康／幸福／知識／人際）、**目前薪資與本年收支**、**總淨資產（現＋股＋房）** 及當前生效的台灣制度。
   - **中欄**：時間軸即時呈現日常切片、**台灣歷史現場**（點擊標題可展開詳情與次層「後世餘波」）、**周圍人的身影**微故事，以及 2027 年後的 **台灣未來預測**。
   - **右欄**：可點擊互動的台灣六大區地圖、4 位同年出生對照同伴、區域 vs 全台存活曲線，以及百歲人生方格。

## 二、起始設定說明（三大開關）

首頁「事件呈現與風險模式」列提供三個可自由切換的起始選項，決定這段人生的資訊密度與風險強度：

| 起始選項 | 預設狀態 | 功能與影響說明 |
| --- | --- | --- |
| **📢 重大惡性社會事件** | **開啟** | 控制是否呈現台灣重大刑案、公安意外與敏感創傷事件細節。**關閉時**會切換為「教學友善模式」（亦可用網址參數 `?edu=1` 直接啟動）：隱藏個人自殺與創傷細節、重大社會刑案改僅呈現「法制與制度改革重點」，且會自動鎖定並關閉「史實模式」。 |
| **⚡ 史實模式** | **關閉** | 僅在「重大惡性社會事件：開啟」時可進一步啟用。**開啟後**，主角會依先天個性、學經歷與所在大區，有機率直接成為重大天災、金融風暴或社會事件之「當事人」，可能面臨鉅額財務損失、長期健康受創，甚至觸發致命結局。 |
| **📚 顯示所有歷史事件** | **關閉** | 控制「台灣歷史現場」卡片的出現頻率。**關閉時（預設）**，系統每 **2–3 年** 才會在當年度符合條件的歷史事件中隨機抽選 **1 則** 顯示，避免事件連發造成資訊過載；**開啟時**，則會完整顯示所有符合當年度與地區條件的台灣歷史事件。 |

## 三、核心特色與系統機制

- **開始工作前零個人資產與合法打工申請（`D01B`）**：出生與求學期間生活費由家庭撫養負擔，開始工作前個人淨資產維持 `NT$0`；僅當滿 15 歲法定打工年齡後，向父母提出課餘打工計畫並成功說服同意（`D01B`），或選擇建教合作、提早學徒就業與大學打工／實習，才會開始累積個人存款。滿法定成年年齡（2023 年前 20 歲、2023 年起 18 歲）後解鎖台股定期定額。
- **生活收支結算、負債危機（`D31`／`D30`）與資產持有檢核**：每年先結算「收入 － 當代生活總支出（依單身／已婚、撫養子女數、區域物價、房租／房貸、長照與養車保養等動態計算）」，現金不足時先賣股支應；若持續負債將依利率滾存，並觸發收支赤字危機（`D31`）或被迫賣房危機（`D30`）。所有賣車、變賣金飾珠寶或賣房選項皆嚴格檢核事前是否實際自購、獲贈、嫁妝或繼承持有。
- **依學群精準分流擇業（`D02`／`D07`／`D07B`）與兵役專業銜接**：大學選系（`D02`）細分為電資理工（`stem_eng`）、醫學藥護（`med_health`）、法政商管人文（`humanities_biz`）與軍警公費（`public_funded`），並將原醫師律師合併職業拆分為獨立的 `car_doctor_pharma`（醫師／牙醫師／藥師）與 `car_lawyer_cpa`（律師／會計師／法務顧問）。透過 `required_majors`／`required_majors_if_uni` 與 `D04` 研發／醫療替代役分流檢查，確保理工生不會出現律師或醫師選項、醫護生不會跳入科技研發役或律師、未雙修跨領域（`uni_cross_coding`）的文商生也不會直接進入半導體或軟體工程跑道；出社會後工作滿 4 年可遇見符合背景的轉職契機（`D07B`），薪水即時依職業倍率與年資連動。
- **各職業年齡資產曲線與世代漏斗校準（v6.1）**：
  - **史實模式雙軌制與時空解耦**：區分「系統性事件」與「單點偶發慘劇」（`incident` 終生上限 1 次、單次低機率），補齊 `east_origin_or_resident` 硬門檻；將跨年拼盤事件（2008 金融海嘯 vs 2009 莫拉克、2014 北捷 vs 2016 小燈泡、2025 vs 2026）全面拆卡，並將經濟衝擊與「顯示所有歷史事件」開關完全解耦。
  - **婚育／北漂漏斗、時代加權自動模式與未接線機制補全**：開放 `D06`／`D17B`／`D18`／`D19` 快速通道並支援多胎與離婚後再婚；實作 `chooseAutoOption` 時代機率加權自動代選；接通高齡租屋受拒事件（`elderly_rent_rejection_risk`）、`D08` 五年外派加給上限與家庭壓力、`D05` 留學財力門檻、留學國清單洗牌（澳／加／德皆可抽中）及 Q3 中產房產繼承。
  - **新增一般民間企業白領與未來壓力測試**：新增 `car_office_white_collar` 並下調中小企業廠主隨機權重；於 2032–2075 補入 1980 竹科、1984 勞基法、1995 健保、1996 直選、2000 政黨輪替、2007 高鐵、2014 太陽花等 7 張歷史里程碑，以及地緣供應鏈、健保財政、百年大旱與大地震等 4 張未來壓力預測卡。
  - 專案隨附 `node scripts/calibrate_cohorts.js` 世代校準驗證腳本。
- **嚴格因果順序、年齡分流與防時代錯亂**：
  - 感情與家庭採嚴格因果鏈：交往（`D17B`）→ 結婚（`D18`）→ 選擇是否生育（`D19`）→ 育兒教育與子女留學（`D21`／`D29`／`cust_postpartum`），未生育不會觸發子女相關事件。
  - 未滿 18 歲遇重大天災或疫情由父母自動代為決策，直接呈現結果與對孩子的影響；日常切片、地區生活標籤、周圍人物微故事與習俗皆依當前年齡與在學／就業狀態過濾（未成年不會看到「朋友不婚不生」或職場同事切片）。
  - 投資工具、職業名稱與選項文案全面採年代分流（如 1961 年前標會／黃金、2003 年後 ETF、2012 年後看盤 App、2018 年後 AI 工程師），歷史事件的「後世制度與社會餘波」改為次層預設收合。
- **周圍人的時代側影（1in8b.life 風格）**：隨年代、年齡與個人學經歷偶爾穿插身邊同學、親友與鄰居的日常切片，呈現單一角色之外的同代人處境。
- **台灣未來預測（2027 年起）**：比照「台灣歷史現場」三段式折疊卡，透過世界旗標與互斥平行分支隨機且符合邏輯地推演未來台灣，並實際影響玩家薪資、持股、房產估值、健康與生活費。

## 四、快速啟動與部署方式

### 1. 本機直接離線運行
解壓縮後直接雙擊 `index.html` 即可遊玩（透過 `data/tw_bundle.js` 離線載入全部 13 份資料庫）。

### 2. 本機靜態伺服器預覽（開發模式）
```bash
python3 -m http.server 8000
# 瀏覽器開啟 http://localhost:8000/
```

### 3. 修改 JSON 後同步離線資料庫
每次編輯任何 `data/tw_*.json` 後，請務必在專案根目錄執行：
```bash
python3 sync_data.py
```
腳本會將全部 **13 份 JSON** 打包同步至 `data/tw_bundle.js`，確保 `file://` 雙擊開啟與線上環境資料一致。

### 4. GitHub Pages 部署
專案已內建 `.nojekyll` 且全部資源皆採 `./` 相對路徑，直接將專案根目錄檔案推送至 GitHub Pages 分支（如 `https://<user>.github.io/<repo>/`）即可運作。

### 各資料庫重點欄位與設計說明

1. **`data/tw_regions.json`**：將台灣劃分為雙北基、桃竹苗、中彰投、雲嘉南、高屏、宜花東與離島六大區，定義出生權重、人口比、區域平均壽命偏移值、家戶所得倍數、房價所得比、產業結構與青年跨區遷徙機率，並納入家戶所得五等分位（Q1–Q5）。
2. **`data/tw_eras.json`**：透過 18 組年代錨點（1950–2070）線性插值並結合 36 個關鍵年份覆寫（如 1974 石油危機、1990 股災、2009 金融海嘯），驅動全遊戲的物價指數（CPI）、平均月薪、基本工資、定存利率、大學錄取率、總生育率與 26 項台灣制度開關（如 1950 勞保、1968 九年國教、1987 解嚴、1995 健保、2005 勞退新制、2019 同婚、2023 新青安）。
3. **`data/tw_lifetable.json`**：以內政部簡易生命表與衛福部死因統計為基準，結合年代死亡率倍率、年齡段死亡率、性別與區域修正、癌症／事故／颱風地震風險，以及台灣 24 小時求助專線清單。
4. **`data/tw_events_history.json`**：完整涵蓋 1950 年美援與地方自治至 2026 年超高齡與 AI 狂潮共 56 起事件；每筆皆含 `summary`、`institutional_aftermath`、`gameplay_impact`、`sources`、`cultural_footnote_en`，重要事件另附 `protagonist_involvement` 供「史實模式」演算當事人機率與後果。
5. **`data/tw_decisions.json`**：收錄 `D01`–`D31` 共 34 張本土關鍵抉擇卡（含打工申請 `D01B`、擇業轉職 `D07`/`D07B`、購車 `D12B`、一卡四劇本金融陷阱 `D14`、戀愛婚育 `D17B`/`D18`/`D19`、消債更生 `D28`、子女留學 `D29`、危機賣房 `D30`、收支赤字債務危機 `D31`）與 5／15／30／50／70 歲暫停反思提問；選項支援 `era_labels` 年代分流文案與嚴格財力／持有資產／因果資格檢核。
